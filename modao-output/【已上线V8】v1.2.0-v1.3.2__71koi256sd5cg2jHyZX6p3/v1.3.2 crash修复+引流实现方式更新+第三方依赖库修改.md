# 3 插屏广告加载动效

## 3.1 页面 1

### 截图

<img src=".exports/v1.3.2 crash修复+引流实现方式更新+第三方依赖库修改/03-插屏广告加载动效/images/001-页面-1-rcUHtzoLUJcyS7oDX5nJF2.png" width="180" />

### 说明

<div style="padding-left:2em"><span style="color:red">批注1</span>：● UI需要做一个全屏的动效页面<br><span style="padding-left:2em">○ 为了处理关闭插屏广告后，A页面到B页面的延迟问题</span><br>【逻辑】<br>1. vip用户因为不弹出广告，也不弹出动效页面<br><span style="padding-left:2em">a. [连接设备成功后的插屏广告] 如果此时需要弹出评分弹窗，也会出现加载动效</span><br>2. 网络较好情况下，先弹出动效页面，再弹出插屏广告，关闭插屏广告后进入B页面<br>3. 网络很差的情况下，动效页面用户会看到两次<br><span style="padding-left:2em">a. 点击A页面，弹出动效页面，进入插屏，关闭插屏进入B页面</span><br><span style="padding-left:2em">b. 点击A页面，弹出动效页面，进入插屏，关闭插屏，弹出动效页面，进入B页面</span><br>4. 动效页面的系统按钮都可以正常使用，不屏蔽<br><span style="padding-left:2em">a. [极限情况] 用户在动效页面点击了系统返回后，到达A页面，A页面仍可以点击</span><br><span style="padding-left:2em">涉及到的插屏广告位：</span><br>1. 连接设备成功后的插屏广告<br>2. 点击设置页面弹出的插屏广告<br>备注：<br>1. 相当于在A页面增加了一个动效页面，就对A页面实行了全屏禁用<br>2. 点击stop mirroring后的插屏广告，因为没有涉及到页面之间的跳转，不需要修改，author(彭俊辉)</div>
