# 3 设备搜索连接

## 3.1 设备搜索连接

### 说明

<div style="padding-left:2em"><span style="color:red">批注1</span>：【设备搜索页面】<br>「页面」<br>1. 页面设计<br>2. 加载的动效<br>「逻辑」<br>1、支持搜索出多个设备，暂时未做设置数量限制，目前不限制搜索到的类型：<br>1.1 Samsung（新、老）、Roku、FireTV、LG（web OS）、Chromecast这部分设备，连接后会有对应的最佳镜像方案<br>1.2 其余设备，点击连接后，跳转系统镜像方案<br>2、已链接设备和未链接设备有状态区别：<br>2.1 已配对状态时点击设备即链接设备，链接成功后直接关闭设备搜索界面，进入对应最佳的镜像方案页面<br>2.2 未配对状态时，点击弹出弹窗提示用户需要操作匹配<br>* 需要匹配的设备：新LG（Pin码连接）、Fire TV（开启ADB）<br>* Fire tv电视未匹配但用户已经关闭弹窗时，进入加载等待状态，（设备旁边没有转圈和✅），需要用户再次点击设备链接<br>3、该界面的设备链接状态与首页的设备状态展示区域一致<br>4、每次打开设备搜索界面，开启设备搜索状态。<br>4.1 10s后未搜索到设备，弹出无设备状态，但持续保持搜索状态<br>4.2 10s内搜索到设备并连接，则停止设备搜索状态。需要用户手动刷新设备或者再次打开设备连接界面，再次开始搜索设备。（一直刷新会导致设备连接状态混乱）</div>

# 5 LG web os 网页UI

## 5.1 LG web os 网页UI

### 说明

<div style="padding-left:2em"><span style="color:red">批注1</span>：【电视屏幕上的LG Webos的web mirror UI】<br>「界面」<br>1. 整个页面<br>2. 四个功能的按钮设计，以及对应状态的按钮设计<br>「逻辑」<br>1. 有“全屏/退出全屏”、“音量调整”、“暂停/启动”、“退出”共计四个功能，假如鼠标在按钮上悬停，有title效果<br>2. “全屏/退出全屏”——Full Screen/Exit full screen<br>2.1 点击全屏，进入全屏模式，“全屏”按钮变为“退出全屏”按钮<br>3.“音量”——Volume；“静音”——Mute<br>3.1 非静音状态下，鼠标悬停在“音量”按钮上时，出现音量调整条，点击进行调整；直接点击“音量”按钮主体，变为静音状态<br>3.2 静音状态下，鼠标悬停在“静音”按钮上时，不出现音量调整条，点击“静音”按钮主体，变成音量调节状态<br>4. “暂停/启动”——Pause/Start<br>4.1 点击“暂停”按钮后，变成“启动”按钮，手机上有操作，但电视上画面停留在暂停时的画面；重新启动后，电视画面更新为手机上当前的画面<br>5. “退出”——Exit<br>5.1 能退出镜像的按钮：物理遥控器上的“电源”；电视浏览器右上角的“关闭”；手机APP内的“stop mirroring”；电视屏幕上的“退出”。<br>5.2 退出是指电视屏幕上停止镜像，画面停留在手机上停止镜像的最后一帧；手机APP内按钮显示“start mirroring”，手机APP内和电视屏幕上的镜像状态保持一致<br>5.3 全屏状态下不出现退出按钮</div>
