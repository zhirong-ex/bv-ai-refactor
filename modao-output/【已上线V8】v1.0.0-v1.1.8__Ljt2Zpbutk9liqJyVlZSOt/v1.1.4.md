# 3 新增获取用户设备信息埋点

## 3.1 新增获取用户设备信息埋点

### 说明

<div style="padding-left:2em"><span style="color:red">批注1</span>：【新增获取用户设备信息埋点】<br>1. 用户打开APP就开始回传，搜索到一个设备就传一个，在一次installs内，需要去重，只回传一次<br>2. 设备信息：类型～manufacturer～modelName～modelNumber～friendlyName～sec:ProductCap～最后有空位的话，返回详细类型信息<br>（拿不到的部分X代替）<br>类型：1: DIAL；2: DLNA；3: ROKU；4: WEBOS；5: Samsung legacy<br>manufacturer：厂商<br>modelName&amp;modelNumber<br>friendlyName：用户自定义设备名称，老设备可能不支持自定义修改设备名称，所以拿到的是设备型号<br>sec:ProductCap：大概率只有samsung设备有</div>
